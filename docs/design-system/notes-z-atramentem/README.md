# Notes z atramentem — dokumentacja dla designerów

**v1 do oceny · 10.11.2026**

[Otwórz pełny dokument HTML](index.html) lub [pełną wersję Markdown](components.md).
HTML działa lokalnie, z relatywnymi zasobami i bez zewnętrznych bibliotek. Wyszukiwarka filtruje rodziny komponentów; pełna treść pozostaje w dokumencie. Pliki i fonty należy zachować razem z HTML.

Dokument obejmuje 30 rodzin, każdą w 11 obszarach, fundamenty wizualne, mapę pokrycia, dostępność, otwarte pytania oraz 44 ekrany i 37 wycinków. Odróżnia wizualne dowody od adnotacji z kodu, rekomendacji i niewykonanych testów. Dwa historyczne załączniki są oznaczone osobno.

Źródło: lokalny prototyp w niezacommitowanym stanie roboczym. Rejestry: [manifest ekranów i pomiarów](evidence/manifest.json), [sumy plików źródłowych](evidence/source-annotations.json).

To dokumentacja bieżącej iteracji dla ludzi, nadal w wersji v1 do oceny. Użytkowniczka zleciła zapis i publikację tej iteracji w repozytorium GitHub. Publikacja zachowuje otwarte pytania projektowe. [Zaktualizowany skill](../skills/notes-z-atramentem/SKILL.md) jest dołączony do repozytorium; biblioteka Figma i rozszerzony pakiet komponentów pozostają poza tą dostawą. Historyczny katalog Poster People `../agent-kit/` pozostaje oddzielny. Kod aplikacji nie został zmieniony w ramach samego dokumentowania.
